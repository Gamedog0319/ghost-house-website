# Ghost House Website — v7 Cinematic Edition

## Start
1. Open this folder in Visual Studio Code.
2. Install Live Server if not already installed.
3. Right-click `index.html` and select **Open with Live Server**.
4. Edit and save any files; Live Server refreshes the page.

## File guide
- `index.html`: Website content, sections, labels, credits.
- `css/style.css`: All colors, fonts, layout, atmosphere, and animation styles.
- `js/main.js`: Website interactivity, gallery, demo, and buttons.
- `assets/media/`: Your real screenshots and GIFs, extracted from the previous self-contained site.

## Edit the cinematic homepage
At the **bottom** of `css/style.css` find `GHOST HOUSE V7 — CINEMATIC GOTHIC DESIGN`.
Those CSS rules control the newer dramatic homepage appearance.

## Note
Web fonts require internet, but the site works offline with fallback fonts.
Review rights to any third-party artwork before making the site public.
